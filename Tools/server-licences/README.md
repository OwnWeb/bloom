# Linux runtime notices

`ICU.txt` is the unmodified licence from Unicode ICU 76.1, used by the Foundation ICU library
in Swift 6.3.3. Source: https://github.com/unicode-org/icu/blob/release-76-1/LICENSE.

`package-linux-server.py` also copies Swift's notice from the build toolchain, the notices of every
SwiftPM checkout it built against, Caddy's licence out of Caddy's own release archive, and Debian's
notices for the shared libraries it includes. Update this ICU notice when changing the Swift
toolchain's ICU version.
